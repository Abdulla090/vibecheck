# VibeCheck

Automated continuous deployment and verification pipeline for VibeCheck, powered by GitHub and Vercel.

## Architecture

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Deployment**: Vercel Edge Network
- **Repository**: [Abdulla090/vibecheck](https://github.com/Abdulla090/vibecheck)
- **CI/CD**: Automatic triggers on push/merge to `main` branch (Squad Alpha & Beta integration)

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
